# 保存到 Folio（Chrome / Edge 浏览器扩展）

采集你正在浏览器中阅读的文章，保留正文、图片位置和原链接。选中一段文字时只采集选区。适用于微信公众号网页版、小红书网页版和具有正文区域的网页；不同网站改版可能影响提取，保存前请在采集箱检查预览。

## 一次安装

1. 下载本仓库或扩展压缩包，解压。打开 Chrome 的 `chrome://extensions`（Edge 使用 `edge://extensions`）。
2. 开启「开发者模式」→「加载已解压的扩展程序」→ 选择含 `manifest.json` 的 `browser-extension` 文件夹。
3. 将「保存到 Folio」固定到浏览器工具栏。

当前提供开发者安装包，尚未发布到应用商店。扩展需安装在 Chrome / Edge，Codex 内置浏览器不支持此安装方式。

## 使用

1. 启动本机工作台，或登录已部署的在线工作台。工作台应在同一个 Chrome / Edge 浏览器里打开。
2. 打开并展开文章，完成网站要求的登录，滚动加载需要保存的内容。点击扩展图标。
3. 工作台地址首次填 `http://127.0.0.1:4318/`，在线版填实际 HTTPS 首页地址。点击「采集到工作台」。
4. 扩展将内容送入工作台「采集箱」。查看预览，选择独立项目（默认）或当前项目，点击「保存到工作台」。新项目不会覆盖原来的导图。
5. 在左侧文章中划选摘录，通过浮框「拖到画布」定位节点；右侧 AI 对话可以读项目资料，聊天文字也可转为节点。

权限仅在点击时读取当前页面，并按需申请你填写的工作台站点访问权限。不会采集未打开的标签页、隐藏正文或绕过付费/登录限制。文章文本与来源先保存在浏览器本机采集箱；保存时服务器尝试获取公开图片，每篇最多 12 张、每张 2 MB。需要登录或防盗链保护的图片可能失败，此时显示链接和提示，不假称已保存完整图片。

如果提示登录或连接失败，先启动服务、完成工作台登录并刷新，再返回原文重新采集。已成功送达的采集箱记录可跨刷新保留；插件中暂存但未送达的记录暂不提供恢复界面。

## 开发验证

在仓库根目录执行 `node scripts/capture-e2e.mjs`。该测试使用隔离浏览器和合成文章，验证正文/选区提取、图片、持久采集箱、新项目导入及原项目保留，不读取真实浏览器资料。
