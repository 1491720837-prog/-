# 页间 Folio

换电脑或交给其他 AI：先读 [AI 接手说明](docs/AI-HANDOFF.md)。个人资料和本窗口聊天备份见本私有仓库的 Releases；恢复时必须核对备份说明中的排除项。

文献、播客逐字稿、采集文章、知识画布和项目 AI 对话，放在同一个阅读工作台。同时保留本机版与独立的在线服务。在线版包含登录、项目版本存储、Mac 助手配对及飞书评论后台；部署与迁移见 [DEPLOYMENT.md](DEPLOYMENT.md)。当前未配置生产云地址。

## 打开工作台

需要 Node.js 22.16+。macOS 可以双击 `start.command`；也可以在本目录运行：

```sh
npm run dev
```

打开 http://127.0.0.1:4318 。已提供 PDF.js 静态资源，正常运行不需要安装依赖。开发或重新准备资源时运行 `npm ci` 和 `npm run prepare:vendor`。

PDF.js 阅读端与解析 Worker 均使用同版本的官方 `legacy` 构建，兼容缺少 `Uint8Array.toHex` 等新方法的浏览器。更新资源后刷新页面即可生效；不要只替换其中一个构建。

## 内容区 → 画布 → 项目 AI 对话

左侧内容工作台容纳原文及中文对照，中间是画布，右侧是可收起的「AI 对话」。拖动分隔线调整内容与画布宽度；阅读文章/播客时收起无关的译文窗，文献仍保留双窗口。画布标题栏「AI 对话」切换聊天窗口。

画布左上角「节点大纲」展开浮动层级目录，点击条目自动展开其祖先分支、定位并选中节点，目录随即收起；Esc 或关闭按钮也可收起。目录按各分支在画布上的上下顺序排列，包含被折叠的节点。左侧为可收起的项目目录，支持按项目名或资料名搜索，点击项目直接切换，切换前保存当前项目。目录底部可新建项目或导入备份，每个项目右侧可下载完整备份。左上角目录按钮展开 / 收起，并记住状态；窄屏时浮在内容区上方。节点大纲与项目目录分开。资料库位于内容区顶部，服务设置与使用指南位于工作台顶部。

每个项目独立保存聊天记录，支持整个画布 / 选中节点 / 不附带节点，这些范围只控制画布节点；每轮必定提供项目全部原始资料的可提取文字，包括 PDF 全文、完整播客逐字稿和文章正文，无法关闭。较长资料由全文检索与分段阅读工具提供，不要求一次塞入提示词。资料完全无法提取时中止提问并提示补充 OCR / 正文，部分空页会在回答的资料说明中列出。发送前可在输入框下选择 Codex 模型；回答显示本次模型和推理强度。完整备份包含聊天记录。

- 点击消息「拖入画布」生成节点，或将该按钮拖到画布指定位置。
- 选中一条消息的部分文字，使用出现的选区按钮点击或拖入画布；节点保留聊天来源、原问题和可用文献依据。
- 本机 Codex 模式下，每个项目聊天对应一个持久 Codex 会话，任务名为 `Folio · 项目名称`；服务重启后续接同一会话。节点内的分支问答仍是独立的单次阅读调用。
- Codex 的文献工具可以检索并读取当前项目的全部原始资料；它不是任意执行系统命令的完整开发代理。Codex 桌面任务里另行输入的消息目前不会反向显示在工作台，建议在工作台继续阅读对话。
- API 模式通过本机/在线网关 `/api/chat` 接入兼容 Chat Completions tools 的服务，可调用资料检索工具。项目聊天要求使用工作台网关 `/api/chat`，拒绝直接填写外部浏览器端接口，以免仅发送片段却无法访问全文。每条新回答可展开「本次可查阅的原始资料」，核对资料名、页/分块数和读取限制；可查阅不等于模型已经逐页阅读全文。

## 播客转写与节点大纲

点击顶部「导入播客」，粘贴公开单集链接。支持小宇宙公开单集、包含音频的节目网页、RSS（选择单集）、公开音频直链，以及已有飞书妙记链接。

流程：解析音频 → 下载 → 上传本人飞书云空间 → 飞书妙记转写 → 完整逐字稿 → 独立项目。保留原有说话人、时间戳和来源链接。节目简介不能充当逐字稿，无法取得公开音频时会说明错误。需要已授权的 `lark-cli` 飞书账号及可用妙记额度。任务保存于服务端，页面关闭不取消；本机服务停机时暂停后续处理，重新启动后继续或提示人工核对不确定的上传。

完成后可打开逐字稿项目、下载 TXT。原项目从「项目」切回。左侧选中文字可摘录、提问、拖到画布。右侧「整理播客内容 → 节点大纲」会读取全部逐字稿分段整理，再生成最多 60 个层级节点；验证通过后一次写入，可撤销。AI 整理与原始逐字稿分开保存，引用只保留能在原稿核对的文字和时间戳。开启已有飞书同步后，新增节点与层级沿用正常同步流程。

## 网页文章采集

使用仓库内 [Chrome / Edge 扩展](browser-extension/README.md)，把当前能阅读的微信公众号、小红书或普通网页采集到工作台「采集箱」。先预览，再保存为独立项目或当前项目资料。正文与公开图片按顺序呈现；选区摘录、节点问答、画布 AI 对话和飞书同步使用同一套交互。受登录/防盗链限制的图片显示保存失败提示和来源链接。开发者安装包尚未上架扩展商店。

## 导入已有中文 PDF

先在左侧打开英文 PDF，再点击中间“中文对照”栏的“导入中文译本”。选择本机中文版，或直接从已导入的文献库中选择配对。译本与原文必须页数相同，按页码对照和同步滚动；保留译本本身的版式和可选文字，无需连接 AI 服务。

配对会自动保存到本机，也包含在完整项目备份中。中文划词产生的节点保留译本名称、页码和选区；没有自动推断逐句对应的英文。通过“管理中文译本”可替换或解除配对，旧摘录文字仍保留。

## Codex 阅读助手

本机版的问答、总结和节点追问默认使用 Codex。先在本机 Codex 完成登录，启动工作台后刷新页面；画布底部显示「Codex 已连接」即可直接划选文字 →「问问 AI」→ 输入问题。无需另外填写 API 密钥，调用使用该 Codex 账户的额度。服务设置中可以检查登录状态、选择可用模型，或切换为 OpenAI 兼容 API。画布底部显示当前模型及推理强度，AI 回答节点保留生成时的模型信息；当前 Codex 请求使用中等推理（medium）。节点侧栏底部的追问输入框内也可快捷选择模型：点击发送按钮左侧的模型名称，菜单向上展开，选中后自动保存并保留提问草稿；选择用于后续提问，已经发送的请求继续使用发送时的模型。

每次提问会附带摘录、原问题、当前节点的祖先分支历史及附近页面；Codex 还可按需检索关联文献全文、读取指定页面，回答引用 PDF 页码。中英文版本分别标记，截图或图片节点会附带实际图片。回答保存在画布节点中，可编辑、继续追问；生成时可取消。在节点编辑栏展开「本次参考文献」，可查看附带页、检索与阅读记录，它们也随完整项目保存。

节点问答每轮根据当前画布分支重建上下文，避免混入兄弟分支；右侧项目聊天则持续使用该项目的独立会话。不会自动导入你在 Codex 桌面应用里的其他聊天。文献文字先提取到本机服务，初始上下文及按需检索结果才发送给模型；不会默认把整篇 PDF 文件上传。单次关联文献最多 3000 页、800 万字符；初始附带附近页面最多 6 万字符，超长页面可继续分段读取。扫描件需要先 OCR，未附带图片的页面只能分析提取出的文字。

需保持本机服务运行。本机版本优先使用 macOS Codex 应用附带的 CLI，找不到时使用 PATH 中的 `codex`；也可在 `.env.local` 设置 `FOLIO_CODEX_BIN` 指定可执行文件路径。后端通过 [Codex App Server](https://learn.chatgpt.com/docs/app-server) 接入，阅读会话禁用命令执行、应用与浏览器工具，只提供当前文献检索和页面读取能力。完整 PDF 翻译使用已登录的 Codex；纯文本段落翻译使用下面配置的 API。

## 配置你的 OpenAI 兼容服务

复制 `.env.example` 为 `.env.local`，填写：

```dotenv
FOLIO_AI_BASE_URL=https://你的服务商/v1
FOLIO_AI_MODEL=你的实际模型名称
FOLIO_AI_MODELS=模型一,模型二
FOLIO_AI_API_KEY=你的密钥
```

`FOLIO_AI_MODELS` 是**允许在界面里选择的模型清单**，英文逗号分隔；不填时只允许 `FOLIO_AI_MODEL` 一个。项目对话必须携带全文检索工具，所以只能选支持 tool calling 的模型：选了不在清单里的模型会直接报“未在允许列表中”，而不是静默跳过检索。

以 OpenRouter 为例：

```dotenv
FOLIO_AI_BASE_URL=https://openrouter.ai/api/v1
FOLIO_AI_MODEL=anthropic/claude-sonnet-5.5
FOLIO_AI_MODELS=anthropic/claude-sonnet-5.5,openai/gpt-6.1-terra-pro,google/gemini-4-argon,deepseek/deepseek-v4.1-flash
FOLIO_AI_API_KEY=sk-or-v1-你的密钥
```

重启服务。在界面顶部“服务设置”里保持网关地址 `/api/chat`，将“问答与总结使用”切换为“OpenAI 兼容 API”，点击“测试连接”。网关在上述 Base URL 后追加 `/chat/completions`。图片问答需选择支持图片输入的模型。密钥仅由本地服务端读取，不进入网页、浏览器存储或导出文件。

**选择模型。**“模型名称”支持输入和下拉：列表来自工作台服务端的 `GET /api/models`（代理服务商模型目录，密钥不出服务端），只列支持 tool calling 的模型并标注上下文长度，输入框仍可手填清单内的任意 ID。输入框下方的模型按钮把 Codex 模型与 API 模型分成两组，选中 API 模型会自动把“问答与总结使用”切到 OpenAI 兼容 API。

**数据政策。**Base URL 指向 `openrouter.ai` 时，请求默认带 `provider.data_collection: "deny"`，避免文献被上游用于训练；其他服务商要启用可设 `FOLIO_AI_DATA_COLLECTION=deny`，明确放行则设 `allow`。

Ollama 也可使用 `http://localhost:11434/v1`，填写已安装的模型，省略密钥。

在线版通过服务端 Secrets 配置相同的 API 环境变量，浏览器保留 `/api/chat` 即可。也可在「在线与本机」配对任意一台 Mac，使用那台设备的 Codex。后台飞书评论模型与当前网页模型分别设置；Mac 离线时可使用云端 API 后备。

## 节点阅读、编辑与原文定位

节点正文按 Markdown 显示有序 / 无序列表、加粗、引用、H1–H6 标题和表格。双击正文进入 Markdown 文本编辑，上方提供加粗、H1/H2/H3、列表与引用按钮；选中文字后点击格式按钮，或按 ⌘B / Ctrl+B 加粗。Esc、⌘Enter / Ctrl+Enter 或点击外部完成编辑并恢复格式显示。编辑器使用独立测量，输入回车不会先收缩内容并重置滚动；重新绘制节点也保留内部滚动位置。

带出处的节点标题栏有「回到原文」，底部出处同样可点击；选中并聚焦节点后按 Alt+Enter 也可定位。按已保存的页码、选区或段落返回；中文出处会展开中文窗。没有精确选区时只能定位到已有页码/段落，纯手写无出处的节点不提供跳转。原文高亮采用淡色和正片叠底，避免盖白文字。

节点 Markdown 与飞书正文共用格式转换：列表映射为原生列表，加粗、引用和正文标题保留格式；飞书的这些格式读回为 Markdown 并在画布渲染。节点层级仍是独立的原生编号树，正文小标题不会变成新节点。新同步格式需重新启动本机服务后生效；沿用已有的冲突和评论锚点保护，不强行覆盖有冲突的文档。

## 已实现

- 内容区 / 画布 / AI 对话三大区域；内容区内支持英文 PDF / 中文对照双窗；可调宽度、收起译文、连续滚动、页码跳转、当前页搜索和阅读缩放。
- 思考画布标题栏的「全屏」可让原文、中文对照和画布一起铺满屏幕，收起顶部导航；点击「退出全屏」或按 Esc 返回。内嵌浏览器不支持屏幕全屏时自动铺满当前窗口，编辑侧栏与弹窗仍可使用。
- 拖动译文与画布之间的分隔线可将画布缩至 120 像素，不受屏幕三分之一或文献栏 45% 的比例限制；窄画布的工具按钮自动换行。
- 导入 PDF、DOCX、TXT、Markdown；多份文献可以共享一张画布。
- PDF.js 文本层划选，自动摘录；浮框提供“直接摘录”“总结概括”“问问 AI”。默认显示节点标题编辑框，修改自动保存；选中“问问 AI”才显示提问框和已学习的快捷操作。手动修改的标题会保留，原文和出处不变。
- AI 回答替换同一摘录节点，保留原文、译文、页码、选区和原问题。失败时保留摘录，可重试、取消。
- 中英文页面均可框选截图，保留页码、选区和对应译本出处；自动译文截图包含页面上的中文文字。截图、粘贴和拖入的图片统一为图片节点，点击图片可查看大图，支持缩放、适应窗口、原始大小及 Esc 关闭；双击标题或正文仍可编辑。
- 图片拖入与粘贴；复制图片或截图后，点击画布按 ⌘V / Ctrl+V，即可在画布现有内容下方生成独立图片节点，支持连续粘贴、撤销 / 重做和自动保存。图片节点支持调节宽度与模型识图。支持 PNG、JPEG、WebP，单张不超过 12 MB；导入时将最长边控制在 2400 像素以内。
- 无限数据层级；按层级循环配色并显示 L1/L2…，无连接节点独立配色。
- 节点四边均有连接圆点：右侧拖向子节点，左侧拖向父节点，上下拖动建立关联。松手直接连线并显示默认文字；点击线上文字可修改类型、方向、说明或删除。已有连接可从端点拖到画布空白处松手断开；共享圆点有多条线时，先点中具体连线再拖动其端点。单击或拖回节点不删除，Esc 可取消，支持撤销 / 重做；断开父子线保留子节点及其下级。阻止循环层级和重复连线。
- 思维导图层级从左向右展开，独立新节点（含摘录、截图、粘贴和拖入图片）自上而下追加到现有内容下方；子节点按父节点实际宽度放在右侧。首次打开旧画布会整理为横向层级，之后刷新保留手动位置。工具栏「整理为思维导图」可按当前节点大小重新整理所有分支，支持撤销 / 重做。
- 节点多轮追问、右侧分支折叠；上下文只沿祖先链构建，不混入其他分支。
- 节点标题不限行数、自动换行，完整显示中文和英文长词；所有节点均可在编辑侧栏调整宽度（180–800 像素），导出画布图片也保留完整标题。新摘录和提问标题不再按固定字数截断。
- 节点可拖动右侧边缘调整宽度、底边调整高度、右下角同时调整宽高。双击右下角或在编辑侧栏点击「适应内容」，自动设置合适宽度并展开全文；手动缩短时正文可滚动，标题保持完整、图片保持比例，连线实时跟随。尺寸自动保存并支持撤销 / 重做，Esc 可取消当前拖拽。
- 双击节点标题或正文，可直接在节点内部编辑，无需打开侧栏；输入时自动保存，Enter 换行，点击外部、Esc 或 ⌘ / Ctrl + Enter 结束编辑。选中节点按 Enter 也可编辑正文。编辑期间保留原生文字选择、输入法和文字撤销，结束后支持画布撤销 / 重做。单击选中、拖动标题移动；追问及详细设置仍在侧栏。
- 第 4 次同类自由提问时，由已配置模型提炼候选快捷操作，确认后添加。
- 相关研究问题尝试 Crossref 元数据检索，保留实际 DOI 来源；不声称已读论文全文。
- 上下文范围选择与发送前预览；选择是否包含原文、译文、历史和图片。可复制、下载 JSON，或直接生成新节点。
- IndexedDB 本机自动保存，撤销 / 重做，项目备份恢复。
- 完整 `.folio.json` 项目、Markdown + 图片 ZIP、画布 PNG、浏览器打印 / PDF。

## 完整中文 PDF 翻译

导入英文 PDF 或 DOCX 后，会询问是否生成完整中文版，并默认提供独立项目选项。DOCX 先在本机转换为保留版式的英文 PDF。完整翻译使用本机已登录的 Codex 和选定的 Codex 模型，会发送文献文字与图片进行翻译和检查。

流程清点每个正文块和每张内置图片，使用 macOS Vision 识别图内文字，翻译后按原坐标排版成中文 PDF。每张图都进行原文 / 译文视觉检查，再检查所有中文页面的排版。全部通过后才自动配对到中文栏，可从“管理中文译本”下载。图注已译不能代替图内翻译，部分完成不能标成完整 PDF。

本机依赖 macOS Vision / Swift、Python（PyMuPDF、Pillow），Word 转换另需 LibreOffice。默认查找 Codex 附带运行时，可用 FOLIO_PYTHON 和 FOLIO_SOFFICE 指定路径。任务和检查记录保存在 artifacts/translation-jobs，不进入发行包。刷新后可继续查看进度，服务重启后可重试，复用已完成段落。一次处理一份完整翻译；取消或失败不覆盖旧译本，结果绑定原项目和文献 ID。

低置信度 OCR、译文溢出或视觉检查未通过会报告具体页码并停止配对，可能需要人工修复。旋转页需先转正。下述旧版段落翻译预览的缓存仍可阅读，新的 PDF 翻译不再以预览替代完整 PDF。

这是文字块级版式保留，不是印刷级 PDF 重排。复杂多栏、旋转文字、公式、彩色背景或密集表格可能需要人工核对；过长译文用虚线标记，块内可滚动查看，不静默截断。扫描 PDF 由完整翻译流程执行 OCR，识别失败时保留原文并报告。PDF 两栏均可连续滚动，按相同页码及页内位置同步；关闭“同步滚动”后可分别阅读。仅渲染视口附近的页面，远处页面保留尺寸占位，避免整篇论文同时占用画布内存。页码随英文阅读位置更新，箭头和输入页码可直接定位。两栏底部均有同步缩放按钮，支持 75%–300% 和 ⌘ / Ctrl + 滚轮；倍率在连续滚动、刷新后保留。“适合正文”根据页面实际墨迹去除外侧白边，同时保留图表；两栏配对时采用共同的安全边界。所有页面按当前倍率重新渲染 PDF，并按屏幕像素密度生成画布。划词、跨页选区和图表摘录按所在页面记录；缩放或调整栏宽时保留阅读位置。示例和文本采用对应段落优先对齐。

## 阅读项目保存与切换

顶部「项目」打开已保存项目列表，每个项目独立保存文献、中英文配对、导图节点、图片、对话和画布位置。首次使用会保留现有工作台并加入项目列表。切换前先保存当前项目；导入 `.folio.json` 会作为新项目打开，原项目仍可随时切回。每项都有「下载完整备份」，建议另外保留一份本地备份。旧标签页的自动保存不会抢占其他标签页刚切换到的项目。

## 数据与导出

本机版数据保存在当前浏览器、当前站点的 IndexedDB，不跨设备自动同步。在线版数据保存在服务器持久化目录，支持跨设备读取及版本检查，浏览器额外保留未提交草稿。本机地址和在线地址属于不同存储空间；使用「在线与本机」整库备份迁移。完整项目包含文档和图片的内嵌数据，不包含模型服务配置。PDF 单文件上限 60 MB，项目恢复文件上限 300 MB。

画布 PNG / 打印导出当前展开的节点；Markdown 与完整项目包含折叠分支。上下文文本会明确区分用户笔记、文献引用、AI 回答。纯文本复制不带图片像素，JSON 上下文包与直接 AI 请求可以带图片。

## 嵌入

在你自己的应用里部署 `dist/`，可通过 iframe 嵌入：

```html
<iframe
  src="https://你的部署地址/"
  title="页间文献阅读工作台"
  style="width:100%;height:900px;border:0"
  allow="clipboard-write"
></iframe>
```

本机网关仅监听回环地址并验证 Host / Origin，不能直接当公共 API 使用。若嵌入跨站 iframe，存储与登录是否可用还取决于浏览器和宿主平台策略。私有 Sites 的登录或平台嵌入限制不由本项目改变。

## 飞书自动同步

顶栏「飞书同步」连接指定的“文献阅读”目录，每个项目一篇文档。开启后保存节点约 8 秒提交，按父子层级生成原生嵌套有序列表（自动编号、加粗标题），表格与图片保留在对应节点，原始问题、出处页码、跨节点关系一起同步；出处与摘录放在同一引用块，不再显示冗余上级说明。PDF 上传到项目文档下并附原文/译本链接。支持已有节点的标题、正文、原始问题双向同步：工作台页面每约 15 秒检查飞书，节点内部段落的增删也会同步；画布位置、连线、图片和文献定位保留。编辑中的节点延后接收；两边不同字段的修改自动合并，同一字段有冲突时在「飞书同步」中选择版本。接收前自动保存本地备份，当前项目可撤销。飞书整节新增、删除、移动，以及图片或出处变化暂不反向转换，检测到时暂停并提示。存在评论时，工作台到飞书的正文重建仍会暂停以保护评论锚点，飞书文字回传不受此限制。工作台页面、本机服务和有效飞书授权均需保持可用；浏览器后台可能延迟轮询。评论 AI 可单独开启或暂停，详见下节。节点与段落映射保存在私有同步状态文件中。

需要本机 `lark-cli` 的有效 user 授权和运行中的工作台服务。关闭网页后已提交任务继续；未提交的改动下次打开补交。映射、原文件摘要和最后成功版本保存在 `artifacts/feishu-sync/`，请随本机项目备份保留。不会删除本地项目，远端原文件不会因节点删除而删除。可在同步面板暂停、查看进度或重试。

## 飞书评论 · 问问 AI

在同步文档中选中文字 → 评论 `AI：问题`。同一评论后续直接追问。同步面板中有单独的评论 AI 开关；只处理当前授权用户自己的未解决局部评论。

- 解释：结合节点、祖先问答、关联文献及页码，在原评论回复。
- 明确要求“添加到正文”：生成子节点，飞书写入并由画布接收后回复结果。
- 明确要求“改写这段”：只替换评论选区，保留其余文字、样式及评论定位；文献出处不改写。
- 明确要求“本篇以后…”或“以后都…”：保存项目或全局偏好，后续评论和工作台阅读问答都读取；可在偏好列表停用，不自动重排历史文档。

问题类型可复用或新增，同类超过 3 次成为快捷操作候选，不自动扩大执行权限。回复标记为 Folio AI，并显示模型与推理强度；飞书账户身份仍是当前授权用户。使用工作台当前选择的模型，页面与本机服务开启时约每 15 秒检查；模型生成另需时间。

私有 artifacts/feishu-sync/comments.json 保存处理记录、分类和偏好，其他模型按 folio-literature 技能读取。每次写入保存基线备份；同一评论回复 ID 不重复处理，失败可重试，不确定的写入暂停核对。评论不会自动解决。评论 AI 采用局部写入；普通画布变化的整篇重建仍受评论保护限制。

## 多来源交互验证

`npm run test:chat-ui` 验证独立项目聊天、选区/拖入节点、刷新恢复、上下文范围、播客大纲层级和备份格式；`npm run test:capture-ui` 验证网页采集；`npm run test:outline-ui` 验证大纲跳转、折叠分支展开、独立滚动和窄画布；`npm run test:projects-ui` 验证项目目录搜索、收起状态、切换保存与备份；`npm run test:sources-ui` 用合成 PDF、长逐字稿和文章验证所有画布范围下的完整资料读取，以及不可读扫描件的明确失败。测试使用隔离的合成数据与模拟接口，不调用真实模型或写入飞书。真实模型、真实转写和飞书同步需要分别验收。

`npm run test:node-reading-ui` 使用隔离项目验证长节点回车滚动、格式工具、来源跳转和刷新保存；`tests/node-markdown.test.mjs` 验证安全渲染及飞书标题/节点层级区分。

### 飞书同步失败时

顶部「飞书同步」可查看各项目最后成功时间与具体错误，点击「重试同步」重新提交。DNS、连接超时等网络故障不会作为正文冲突永久阻止同步；重试仍会先校验飞书版本，并保留真实的内容冲突与评论保护。服务升级后需要重启本机服务并刷新工作台。当前本机模式要求服务和工作台页面运行。
